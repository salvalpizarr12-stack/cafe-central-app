
# Café Central – Sistema de pedidos

## Descripción
Café Central es un proyecto de aplicación web que permitirá a los clientes consultar el menú de una cafetería, conocer los precios y realizar pedidos desde una computadora o dispositivo móvil.

## Problema que resuelve
Busca facilitar la consulta de productos y la realización de pedidos, evitando confusiones y mejorando la organización de la cafetería.

## Funcionalidades principales
- Consulta del menú.
- Visualización de precios.
- Registro de clientes.
- Selección de productos.
- Creación de pedidos.
- Consulta del estado de los pedidos.
